# MercadoLibre AI — base inicial

Este proyecto crea dos endpoints públicos en Netlify:

- `/api/mercadolibre/callback`
- `/api/mercadolibre/notificaciones`

## Importante

Esta primera versión confirma que las URLs existen y responden correctamente.
Todavía no guarda tokens ni datos de ventas. Eso se agrega en la siguiente etapa
mediante variables de entorno y una base de datos.
