# Rocko's Intelligence V6 — SEO Capture

- Se elimina la dependencia de búsquedas públicas desde Netlify para Competencia SEO.
- Se incorpora una extensión para Chrome/Edge que captura hasta 150 resultados desde la sesión normal del usuario.
- La extensión descarga un JSON con posición, MLA, título, precio, tipo orgánico/patrocinado, envío, vendedor, imagen y enlace.
- La aplicación permite importar la captura y comparar la publicación propia contra los resultados observados.
- Se muestran posición observada, resultados capturados, promedio de precio Top 10 y competidores.
